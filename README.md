# 🛒 Instacart Market Basket Analysis

## 📌 Project Overview

This project analyzes **Instacart grocery transactions** to discover which products customers frequently purchase together.

Using **Python, FP-Growth, and Association Rule Mining**, the project identifies product relationships and builds a simple **product recommendation system**.

## 🎯 Objectives

* Find frequently purchased products
* Identify products commonly bought together
* Generate association rules using **Support, Confidence, and Lift**
* Build a product recommendation engine
* Visualize product relationships using a co-purchase network

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* MLxtend
* NetworkX
* PyVis

## 📊 Key Results

* **1,900** frequently purchased products
* **974** frequent itemsets
* **151** association rules
* Built a product recommendation engine
* Created an interactive product co-purchase network

## 💡 Business Value

The analysis can help e-commerce businesses with:

* Product recommendations
* Cross-selling
* Product bundling
* Personalized shopping experiences
* Promotional strategies
